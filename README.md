# open.json-to-csv-tsv

> A lightweight, zero-dependency Node.js utility to convert JSON arrays into CSV or TSV strings.

[![npm version](https://img.shields.io/npm/v/@journey-to-code/json-to-csv-tsv.svg)](https://www.npmjs.com/package/@journey-to-code/json-to-csv-tsv)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Features

- ⚡ **Zero dependencies** — pure modern JavaScript.
- 🔄 **CSV & TSV support** — seamlessly output commas or tabs.
- 🛡️ **Auto-escaping** — handles nested quotes, commas, and multiline values safely.
- 🎯 **Custom headers** — specify explicit headers or auto-detect from keys.

## Installation

```bash
npm install open.json-to-csv-tsv
